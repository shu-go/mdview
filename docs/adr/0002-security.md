# ADR 0002: 表示する文書を信頼しない

- 状態: 採用
- 日付: 2026-11-21

## 背景

ページは Wails のバインディング（外部エディター起動、設定保存、ファイルを開く等）を呼べる。
閲覧する Markdown は第三者が書いたものでありうるため、文書内の生 HTML・Mermaid・リンクから
任意コード実行やローカルファイル流出に繋がってはならない。

## 決定

1. **HTML サニタイズ（Go, bluemonday）**: 生 HTML は許可するが、`<script>`、イベントハンドラー属性、
   `javascript:` 等を除去する。`data-*` 属性は mdview が生成するものだけ許可し、
   Wails ランタイムの `data-wml-*`（ウィンドウ操作・イベント発火）は通さない。
2. **Mermaid の SVG サニタイズ（DOMPurify, SVG プロファイル）**。
3. **CSP**: `script-src 'self'` などで、サニタイズ漏れがあってもインラインスクリプトを実行させない。
4. **ローカルファイル配信** (`/_mdv/file`) は画像・動画・音声の拡張子に限定し、
   Windows ではドライブレター付きのパスのみ（UNC/デバイスパス拒否：NTLM 資格情報の漏洩防止）。
   判定は `internal/safepath` に一本化し、描画時（画像 URL 生成での stat など）も
   文書由来のネットワークパスには一切アクセスしない。
5. **外部への遷移**: `OpenURL` は http/https/mailto のみ。Markdown 以外のローカルファイルを
   リンクから開く場合は確認ダイアログを出す。
6. **リンク先の検証は Go 側**: 文書内リンクは `OpenLink` を通し、ネットワークパス（混在区切りを含む）を拒否する。
   `data-mdv-path` は生 HTML で偽装できるため、フロントエンドの判定には頼らない。
   ユーザー自身が指定するパス（コマンドライン・ダイアログ・ドロップ）は `OpenPaths` で従来どおり許可する。
7. **ページ遷移の禁止**: リンクのクリック／中クリックはすべて横取りし、アプリ以外のドロップ（URL・テキスト）は
   既定動作を止める。ページがバインディングを呼べるため、WebView が別ページに置き換わってはならない。
8. **リモートデバッグ（CDP）ポート**は開発ビルド（`production` タグなし）でのみ
   `MDVIEW_REMOTE_DEBUG_PORT` で有効化できる。

## 影響

- 文書内の `<iframe>`、インラインスクリプト、任意の `data-*` 属性は表示されない。
- UI テストで Playwright の `waitForFunction`（eval）は CSP により使えない。`evaluate` でポーリングする。
